Model & equations
P = Kp · (B/2)0.8 · (D/12)4 · (pitch/12) · (RPM/1000)3 [W]
Shaft power. Base formula (2-blade): Boucher, The Electric Motor Handbook — P = k·pitch·D⁴·N³, pitch/D in feet, N in kRPM. ±10–15% for conventional planforms. The (B/2)0.8 blade-count factor is a community heuristic, origin untraced (see README ref. 6) — mechanism established (NACA TN-698), exponent unpublished; calibrate Kp per blade count from test data.
Q = 60·P / (2π·RPM) [N·m]
Torque — exact, from P = τ·ω.
T = (2·ρ·A·(FM·P)2)1/3, A = π(0.0254·D)2/4 [N]
Static thrust — hover momentum (actuator disk) theory: FM = (T3/2/√(2ρA)) / Pshaft, rearranged for T. Standard reference: Leishman, Principles of Helicopter Aerodynamics, Cambridge Univ. Press. Typical FM for small props: 0.5–0.7 (published); low-Reynolds props can fall to ~0.4.
RPMmax = K / D
Manufacturer structural limit (constant tip speed). K per APC published limits (apcprop.com/technical-information/rpm-limits): slow flyer 65k, multi-rotor 105k, folding 120k, thin electric 150k, glow/sport 190k, racing carbon (IC) 225k, racing electric 270k. APC props only — other brands: check the datasheet.
